# Заметки для сборки установщика (Installer Notes)

## Внешние зависимости (MPV)
Приложение AnimeLib Desktop не имеет встроенного видеоплеера и делегирует воспроизведение эпизодов внешнему плееру `mpv` через вызов `std::process::Command`.

**ВАЖНО ПРИ СОЗДАНИИ УСТАНОВЩИКА:**
- Установщик (например, NSIS, Inno Setup или WiX Toolset) должен **обязательно** учитывать наличие `mpv` в системе пользователя.
- **Возможные решения:**
  1. **Включить `mpv.exe` в сборку:** Положить исполняемый файл `mpv.exe` (и необходимые ему DLL, если используются) прямо в папку рядом с `animelib-desktop.exe` при установке, чтобы программа могла запускать его напрямую по относительному пути `./mpv.exe`.
  2. **Установка скриптом (winget):** Использовать скрипт установщика для вызова `winget install --id shinchiro.mpv -e` на этапе инсталляции, если плеер не найден.
  3. **Добавление в PATH:** Если mpv устанавливается в отдельную директорию, убедиться, что установщик добавляет эту директорию в переменную среды `PATH`.

Без `mpv` пользователи не смогут воспроизводить видео и будут получать ошибку `Failed to launch mpv: program not found`.
